# Pöhls Immobilien – Zweisprachigkeit (DE/EN) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die komplette Seite auf Deutsch (`/`) und Englisch (`/en/…`) ausliefern, Inhalte im Directus-Translations-Format.

**Architecture:** `@nuxtjs/i18n` 10 mit `prefix_except_default` und eigenen englischen Pfaden. Oberflächentexte in Locale-JSONs, sprachabhängige Formatierung und Fachwörterbücher als reine Utils mit `locale`-Parameter. Das Build-Skript erzeugt `translations`-Arrays; `useContent.ts` liefert lokalisierte Objekte.

**Tech Stack:** wie Hauptplan + `@nuxtjs/i18n@^10.6`.

**Spec:** `docs/superpowers/specs/2026-09-25-poehls-i18n-design.md` (Ergänzung zu `2026-09-25-poehls-prototyp-design.md`).

## Global Constraints

- Alle Constraints des Hauptplans gelten weiter (Tokens, Schrift, Buttons, noindex, keine Google Fonts).
- Deutsche URLs bleiben unverändert; Englisch unter `/en/` mit den Pfaden aus Spec I2.
- Kein sichtbarer Text im Template mehr hart codiert: Oberfläche über `t()`, Inhalte über `useContent`.
- Jede englische Inhaltsübersetzung trägt `machine_translated: true`.
- Datenschutz/AGB bleiben deutsch (Hinweis auf EN-Seiten).
- Links immer über `localePath()` bzw. `<NuxtLinkLocale>`.

## Review Focus

1. **Sprachwechsel auf Detailseiten und gefilterten Listen** (`/angebote/<slug>?…` → `/en/properties/<slug>`): Umschalter behält Slug und Filter-Query. → Browser-Check in Task 8.
2. **Gemischte Sprache auf EN-Seiten** (deutsche Reste in Chips, Trefferzeile, Fehlermeldungen, aria-labels): → Browser-Skript Task 8 sucht deutsche Wörter.
3. **Englische Zahlenformate** im Preisfilter und in Chips („up to €500,000“): → Tests Task 2.
4. **Fehlende Übersetzung** eines Objekts: Seite zeigt deutschen Text statt leer; Test meldet Lücke. → Tests Task 3/4.
5. **hreflang/`lang` korrekt pro Sprache** und keine 404 auf `/en/…`-Objektseiten im Prerender. → Task 1 + Task 8.
